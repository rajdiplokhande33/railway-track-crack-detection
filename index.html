NAME OF PROJECT


🚆Railway Track Crack Detection System🔍

📌about project


this project is designed to detect crack or faults in railway track and provide an alert

⚙️Components


  1. Ardunio

  2. IR sensor

  3. GSM

  4. LCD

  5. BUZZER


🔃WORKING

  • The IR sensors check possible crack or irregularities
  • The sensor sends the signal to the ardunio
  • If a crack is detected, the Arduino activates the buzzer and LED
  • The LCD display shows a warning message such as “CRACK DETECTED”
  • If a GSM module is used, an alert message can also be sent
  • If no problem is detected, the system shows “TRACK SAFE”
